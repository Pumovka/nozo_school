# Доступность

## Цель

NOZO School разрабатывается так, чтобы пользователям с разными потребностями было проще воспринимать учебные материалы и пользоваться интерфейсом.

Это рабочие принципы разработки. Они не означают, что все перечисленные функции уже реализованы или что сайт прошёл официальную проверку доступности.

## Что учитывать в интерфейсе

### Для пользователей с нарушениями слуха

- Не передавать важную информацию только через звук.
- Для видео по возможности предоставлять субтитры и текстовую расшифровку.
- Важные инструкции и сообщения показывать в текстовом виде.

### Для пользователей с нарушениями зрения

- Использовать семантические заголовки и HTML-элементы по назначению.
- Обеспечивать работу основных сценариев с клавиатуры.
- Делать фокус клавиатуры заметным.
- Давать изображениям осмысленные текстовые описания, если они передают информацию.
- Подписывать поля формы и кнопки понятным текстом.
- Проверять порядок чтения и совместимость ключевых сценариев со скринридерами.

### Для всех пользователей

- Поддерживать читаемый размер текста и достаточный контраст.
- Не полагаться только на цвет для передачи статуса.
- Использовать понятные названия действий и сообщения об ошибках.
- Сохранять последовательную структуру страниц.
- Не запускать звук или движение без необходимости.
- Проверять интерфейс на узких экранах и при увеличении масштаба.

## Проверка перед публикацией

Для каждой новой страницы проверьте:

- [ ] Основной сценарий можно пройти клавиатурой.
- [ ] Видно, какой элемент сейчас в фокусе.
- [ ] У кнопок и полей есть понятные названия.
- [ ] Заголовки идут в логичном порядке.
- [ ] Контраст текста и элементов управления достаточен.
- [ ] Ошибки и статусы понятны без опоры только на цвет.
- [ ] Видео и аудиоматериалы имеют доступную альтернативу, если она нужна.
- [ ] Интерфейс работает при увеличении масштаба.
- [ ] Проверены мобильный экран и основные состояния интерфейса.

## Стандарт

При разработке ориентируемся на WCAG 2.2 уровня AA. Полное соответствие можно заявлять только после проверки сайта и исправления обнаруженных проблем.
